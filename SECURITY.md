# Security Policy

## Supported Versions

All versions of this project are currently supported with security updates on a best-effort basis.

| Version | Supported          |
| ------- | ------------------ |
| All     | :white_check_mark: |

## Data Privacy & Local Storage

This application runs completely **locally on your device**.
* No personal data, inputs, or settings are collected, transmitted, or stored on any remote servers.
* All software updates are fetched exclusively from the public [GitHub Releases](https://github.com/mgrabovac22/gitswamp/releases) page.

## Reporting a Vulnerability

If you discover a security vulnerability, please do not report it publicly through standard GitHub Issues to protect users.

Instead, please report it using one of the following methods:
* Sending a private message / contacting the project maintainer directly.
* Opening a private GitHub Security Advisory on the repository, if enabled.

**What to expect:**
* **Response:** You can expect an initial response within 48 to 72 hours.
* **Updates:** We will keep you informed about the verification status and the progress of the patch, though no specific resolution timeline is guaranteed.
* **Disclosure:** Once the vulnerability is patched, a security advisory and a new release containing the fix will be published directly on our GitHub Releases page.
